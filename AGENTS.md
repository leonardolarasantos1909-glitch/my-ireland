# Publicação do My Ireland

O mantenedor autorizou este fluxo como padrão para futuras alterações neste repositório.

- Confira o destino `origin` (`leonardolarasantos1909-glitch/my-ireland`) e atualize a referência `origin/main` antes de preparar a publicação. Inclua somente as alterações da tarefa.
- Preserve dados, configurações e funcionalidades existentes. Mantenha arquivos necessários e obtenha autorização específica antes de alterar segurança, autenticação ou infraestrutura.
- Execute `npm test` e `npm run build` antes de cada publicação. Se houver falha, conflito ou erro de permissão, interrompa a publicação e informe o problema.
- Use commits identificáveis e publique diretamente na branch `main` com push normal, sem abrir pull request. Confirme que o envio avança a referência remota sem sobrescrever alterações. Nunca use force push.
- Depois do envio, confira o SHA de `refs/heads/main` no GitHub e informe o commit publicado. Confirme o deploy do Cloudflare somente quando houver evidência independente.
